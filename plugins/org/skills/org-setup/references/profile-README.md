## How work moves here

Work starts as a GitHub issue and moves through `stage:brief`, `stage:research`, `stage:plan`,
`stage:execute`, `stage:review` and `stage:done`. Every change reaches `main` through a pull request
that passes the required checks. The record of each piece of work stays on its issue.
